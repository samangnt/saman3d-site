## ⚙️ Our AI-Accelerated Pipeline

We rely heavily on large language and vision models (primarily Anthropic's Claude 3.5 Sonnet) as our core technical co-developer across our entire stack:

*   **Programmatic 3D Automation:** Generating complex Python (`bpy`) scripts to automate repetitive Blender tasks, procedural kitbashing, and batch rendering.
*   **Game Engine Scripting:** Rapidly prototyping and debugging Luau (Lua) for client-server Roblox architecture, and C#/C++ for standalone game mechanics.
*   **Multimodal QA:** Utilizing Vision APIs to analyze rendered frames and detect mesh clipping, texture seams, and lighting inconsistencies.
